# hashlib.sha256

- 语言: Python
- 库/模块: 标准库 `hashlib`
- 导入: `import hashlib`
- 用途: 创建 SHA-256 哈希对象;常作 `hmac.new` 的 `digestmod`,也用于一次性算报文摘要、内容去重
- 官方文档: https://docs.python.org/3/library/hashlib.html#hashlib.sha256

## 词源

- `hash` -> hash(哈希/散列)= 把任意长度数据压成固定长度指纹
- `lib` -> library(库)= 标准库
- `sha` -> Secure Hash Algorithm(安全哈希算法)
- `256` -> 输出 256 bit = 32 字节 = 64 个十六进制字符
- `usedforsecurity` -> used for security(用于安全用途)= 给 FIPS 环境标注用途的开关
- `hexdigest` -> hex(十六进制)+ digest(摘要)

## 最小例子

```python
import hashlib
import hmac

# 最常见:当 HMAC 的 digestmod 用,传构造器本身
mac = hmac.new(b"secret", b"payload", hashlib.sha256)
print(mac.hexdigest())            # 64 个 hex 字符

# 直接算摘要
h = hashlib.sha256(b"abc")
print(h.hexdigest())
# ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
print(len(h.digest()), len(h.hexdigest()))   # 32 64

# 增量 update(只收 bytes-like)
h2 = hashlib.sha256()
h2.update(b"a")
h2.update(b"bc")                 # 等价于一次 update(b"abc")
assert h2.hexdigest() == hashlib.sha256(b"abc").hexdigest()

# 空输入也有合法摘要
print(hashlib.sha256().hexdigest())
# e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
```

小抄:SHA-256 的 `digest()` 固定 32 字节,`hexdigest()` 固定 64 字符。

## 参数（常用在前）

| 参数 | 必填 | 类型 | 默认 | 词源 | 含义 | 易错点 |
|------|------|------|------|------|------|--------|
| `data` | 否 | bytes-like | `b''`(省略等价空输入) | data(数据) | 要立刻哈希的初始数据 | 只收 bytes-like;传 str 抛 `TypeError: Strings must be encoded before hashing`,先 `.encode()` |
| `usedforsecurity` | 否 | bool | `True` | used(被使用)+ for(为了)+ security(安全) | 标注该哈希是否用于安全目的 | 关键字-only(`*` 之后),只能 `usedforsecurity=False` 这样传;FIPS 环境下 `False` 才允许用非核准算法,普通项目不用管 |

返回对象接口(都常用):

| 方法 | 返回 | 说明 |
|------|------|------|
| `.update(data)` | `None` | 追加 bytes-like 数据;`update(a); update(b)` == `update(a+b)`;不收 str |
| `.digest()` | `bytes` | 32 字节原始摘要 |
| `.hexdigest()` | `str` | 64 字符小写十六进制,无参数 |
| `.digest_size` / `.block_size` | `int` | 32 / 64 |

## 和它一起出现的

- [`hmac.new`](../hmac/new.md):最典型的组合,`digestmod` 传构造器 `hashlib.sha256`;传 `"sha256"` 也可以,但别写 `"SHA256"` 这种大小写混写(名字要能被 `hashlib.new` 识别)。
- [`hmac.compare_digest`](../hmac/compare_digest.md):比较外部给的摘要时用它,不要 `==`。
- [`str.encode`](../stdtypes/str-encode.md):字符串数据进 `data` / `update` 前必须编码。
- `hashlib.new("sha256")`:按名字创建哈希对象,等价 `hashlib.sha256()`;`hmac` 的 `digestmod` 也接受这种名字形式。
- `hashlib.file_digest`(3.11+):直接算文件摘要,大文件不必手写分块读取。
